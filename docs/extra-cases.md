# 확장 사건 팩 (경찰 검거 · 사기 · 불륜 현장)

보이스피싱 중심이던 사건 팩에 주제를 더했다(2026-11-06).
규칙·정답 구조는 그대로이고, 사건마다 이야기 파일 하나(`godot/data/story/<preset>.json`)와 팩 하나(`godot/data/puzzles/<preset>-<seed>.json`)가 붙는다.
기존 팩과 `index.json` 앞 16개는 건드리지 않았고, 새 사건은 목록 맨 뒤에 8개를 더했다.

## 설정 메모
- **불륜 현장:**
  - 실제로는 경찰이 검거하는 사건이 아니라서 '특별 의뢰'(이혼 소송 증거 확보)로 틀을 잡았다.
  - 제안 카드의 머리글이 "Gleo · 특별 의뢰"로 바뀌고, 결말 문구는 '검거' 대신 '포착'을 쓴다.
  - 문구는 "비밀 약속", "알리바이"까지만 쓰고 수위 높은 표현은 넣지 않았다.
  - 공용 연출(핀 위 "검거" 도장, Gleo 현장 한마디 "검거!")은 코드 공용이라 그대로다.
- **뺑소니:** 부상자가 없는 물피 사고로 잡아 가볍게 즐길 수 있는 톤을 지켰다.
- 실존 인물 · 기관 · 상표는 쓰지 않았다(수배 번호, 중고장터, 리딩방은 모두 가공).

## 만든 방식
| 바꾼 것 | 위치 |
|---|---|
| 새 난이도 구성 8개(악역 구성 · 말썽꾼 · 익명 · 예산 · 악역 화면 이름) | `prototype/puzzle/rules.py` (`PRESETS`, `Preset.labels`) |
| 악역 화면 이름 반영(`roles[key].label`) | `prototype/export_pack.py` (`roles_table`) |
| `--merge-index`: 팩 목록을 덮어쓰지 않고 이 사건만 더하기 | `prototype/export_pack.py` |
| 이야기 8개(제안 · 브리핑 3장 · 수법 · 이름 · 최종 단계 · 결말) | `godot/data/story/<preset>.json` |
| 사건 팩 8개 | `godot/data/puzzles/` |
| 팩 목록 | `godot/data/puzzles/index.json` (맨 뒤에 8개) |
| 파이썬 테스트가 새 난이도 8개를 포함 | `prototype/tests/test_puzzle.py` |

- 악역 이름(`roles` 표의 THUG · BLACKMAILER · BOSS)은 사건마다 다르게 나온다. 예: 수배범 / 도피 조력자, 먹튀 판매자, 바람잡이 / 방장 / 총책.
- 제보자 직업 7종 + 오지랖 + 취객은 그대로다. 이름 목록만 사건마다 따로 두었다.

### 팩을 다시 만들거나 더하는 법
```bash
cd prototype
python3 export_pack.py --only wanted:2000 usedgoods:2300 affair:2601 hitrun:2200 romance:2500 reunion:2706 theft:2101 invest:2402 --out ../godot/data/puzzles --merge-index
```
- 같은 명령을 다시 돌리면 팩과 `index.json`이 똑같이 나온다(확인함).
- `--merge-index` 없이 `--only`를 쓰면 `index.json`이 그 사건들만 남고 덮어써지므로 주의한다.
- 시드를 고를 때 지킨 조건:
  - 봇이 찍기 없이 풀 수 있고, 최소 탐문 수가 예산보다 적다.
  - 같은 직업 두 명이 나오는 판이다.
  - 길가 장소가 경로 끝(진행률 0.97 이후)에 없다(`test_puzzle_case` 잠복 검사).
  - 길가 랜드마크 자리가 도로·보도 밖에 있다(`test_adas_world`).

### 제보자 얼굴 규칙 (`PortraitBank`)
- 새 이름 목록도 기존 규칙에 맞췄다.
  - 순찰 경관은 한 · 서 · 도로 시작하는 이름 3개(얼굴 3종).
  - 동네 토박이는 이름에 '할머니' 또는 '할아버지'를 붙인다(얼굴은 이름의 성별).
  - 나머지 직업은 직업마다 얼굴이 하나다.
- 새 팩 제보자 72명 전원에게 얼굴이 있다(`test_portrait_bank`).

### 음성
- 새 팩은 음성이 없다. `VoiceBank`가 팩 id를 목록에서 못 찾아 자막만 나온다(기존 동작 그대로).
- ElevenLabs 슬롯이 가득 찬 상태라 이번에는 만들지 않았다.

## 한계
- 제보자 대사 자체는 퍼즐 공장 템플릿 그대로다("수상한 데가 한 곳 있어요"). 사건별 말투는 이야기 파일의 이름 · 카드 문구 · 결말에만 있다.
- 장소 이름과 3D 건물은 기존 업종(역 · 공원 · 카페 · 시장 등)이다. 사건 소재에 맞는 장소(정비소, 숙소 등)는 없다.
- 기존 `hard-1001.json`은 지금의 퍼즐 공장 코드로 다시 뽑으면 도시가 달라진다(이번 변경과 무관, 예전 버전으로 만든 팩). 기존 팩을 다시 내보낼 때 주의한다.
