## 1. 한 줄 소개와 타깃

**내비게이션 지도 위 실제 장소 9곳 중 조직원이 숨은 곳을, 제보자들의 엇갈리는 증언을 맞춰보며 도착 전에 찾아내는 1인 음성 추리 게임.**

- **타깃 상황:** 완전 자율주행 차량에서 혼자 이동하는 탑승자. 출퇴근처럼 15~40분 걸리는 이동.
- **Gleo의 역할:**
  - 수사 파트너로서 브리핑, 요약, 확인 질문을 맡는다.
  - 제보자 9명의 목소리를 연기한다.
- **디자인 원칙**
  1. **지도가 곧 수사 보드:** 단서는 모두 지도 위 도형으로 남는다.
  2. **듣고, 흘깃 보고, 말한다:** 음성이 중심이고, 화면은 짧게 확인하는 용도다. 멀미를 고려했다.
  3. **언제나 논리적으로 풀 수 있다:** 진실은 엔진이 정하고, 답이 하나뿐인지 검증된 퍼즐만 낸다.
  4. **실제 이동이 게임이 된다:** 도착 시간, 지나가는 길, 터널, 정차가 모두 게임 규칙에 들어간다.

### 세계관과 톤 (확정)
- **테마:** 조직원 잠복. 현대 한국 형사 드라마 톤이다.
- **플레이어:** 광역수사대 형사. **Gleo:** 수사 파트너.
- **적:** 범죄 조직 하나(이름 미정). 사업부 3개(보이스피싱, 불법 도박, 밀수)와 보스로 이루어져 있다(7절).
- **제보자:** 우리 동네 사람들. 노점상, 택시기사, 배달 라이더 같은 직업이다.
- **아트 방향:** Pleos 차량 화면(밝은 테마의 자율주행 시각화 + 내비)을 그대로 쓰고, 게임 요소에만 경광등 빨강·파랑 액센트를 준다. 3D는 로우폴리.
- **표현 수위:** 검거 중심으로 하고 폭력 묘사는 최소화한다. 장소는 "근처에 숨어 있다"로 표현한다(3절).

## 2. 핵심 루프

```
브리핑 → [탐문 → (추가 질문) → (메모)] × N → 급습 → … → 승리 / 패배
```

| 단계 | 플레이어 행동 (음성 / 탭) | 결과 |
|---|---|---|
| 브리핑 | — | Gleo가 9곳, 숨은 곳 수, 용의 목록, 탐문 예산, 마감(ETA)을 안내 |
| 탐문 | "3번 탐문해줘" / 핀 탭 | 제보자가 나와 자기 직업을 밝히고 단서 1개를 말함. 단서가 지도에 도형으로 그려지고 예산 -1 |
| 추가 질문 | "어떤 사람이었어요?" | 캐릭터 대화. **새로운 논리 정보는 주지 않음** |
| 메모 | "3번 의심 표시" / "3번 무고 표시" | 핀 테두리 색이 바뀜 |
| 정리 | "지금까지 정리해줘" | Gleo가 장소별 단서와 밝혀진 사실(예: 같은 직업이 두 명)을 읽어줌. 추론은 하지 않음 |
| 힌트 | "힌트 줘" | 신뢰도 -1. "2번과 6번의 말은 동시에 참일 수 없어요"처럼 모순 쌍 하나를 짚어줌 |
| 급습 | "8번 급습해" → 확인 질문 → "해" | 정체 공개. 숨은 곳이면 검거, 아니면 신뢰도 -2 |

### 승리와 패배
- **승리:** 숨은 곳을 모두 급습해 검거한다.
- **패배(해임):** 신뢰도가 0이 된다.
- **패배(도주):** 도착할 때까지 다 못 잡는다. 검거한 수만큼 부분 점수를 준다.
- **최종 단계:** 도착 5분 전에 "조직이 눈치챘어요"라는 알림이 나오고, 그때부터는 탐문할 수 없고 급습만 가능하다.

## 3. 보드 생성 규칙

### 보드 방식
| 방식 | 장소를 고르는 범위 | 언제 쓰나 |
|---|---|---|
| **경로형 (기본, 확정)** | 출발지에서 목적지까지 경로 양쪽 약 1.5km 안 | 목적지가 있을 때. "잠복 찬스"가 자연스럽게 생긴다 |
| 주변형 (보조) | 현재 위치 반경 2~3km | 목적지가 없거나 너무 가까울 때만. 오래 달리면 차가 보드에서 멀어지므로 짧은 이동이나 정차 중에 맞다 |

### 장소 선정 기준
1. **후보 수집:** 랜드마크와 공공장소(역, 공원, 시장, 미술관, 도서관, 광장, 타워)를 우선 모은다.
   - 자주 가는 곳은 사용자가 동의한 경우에만 최대 2곳 넣는다. 집은 기본으로 제외한다.
2. **분산:** 장소 사이 최소 700m 간격을 둔다. 차량 화면 하나에 경로 전체를 담았을 때 핀이 겹치지 않는 간격이다.
   - 경로형은 경로의 앞, 중간, 뒤 구간에 각각 3곳 정도씩 나눈다.
3. **다양성:** 같은 종류는 최대 3곳까지만 넣는다. 그래야 "카페들은…" 같은 종류 단서가 의미가 있다.
4. **길가 장소:** 경로에서 300m 안에 있는 장소는 정확히 2~3곳만 고른다(잠복 찬스 대상). 나머지는 경로에서 0.5~1.5km 떨어진 곳에서 고른다.
5. **장소가 부족하면:** 범위를 넓히고, 그래도 부족하면 가상 장소(예: "골목 포장마차")를 섞는다.
6. **번호와 이름:**
   - 경로형은 경로 진행 순서대로 1~9번, 주변형은 북서쪽부터 차례로 번호를 붙인다.
   - 이름은 짧은 별칭으로 줄인다(예: "○○시립미술관" → "미술관").
   - 음성으로는 번호와 이름 둘 다 알아듣는다.
7. **고정:** 판이 시작되면 9곳은 차가 움직여도 바뀌지 않는다.

### 표현 원칙
- "그 장소가 범죄 소굴"이라고 하지 않는다. **"그 근처에 조직원이 숨어 있다"**로 표현한다.
- 실제 상호에 범죄 이미지를 붙이지 않기 위해서다.

## 4. 단서 유형 (룰 v1: 경로 기준)

H = 숨은 곳의 집합이다. 장소 번호는 지나가는 순서이고, 왼편/오른편은 진행 방향 기준이다.

| 코드 | 단서 | 대사 예시 | 지도 표시 | 참이 되는 조건 |
|---|---|---|---|---|
| RADIUS | 반경 | "이 역에서 1km 안에 수상한 데가 딱 한 곳 있어요" | 주변 검색 반경 원 | 반경 안(자기 장소 제외)에 있는 숨은 곳 수 = N |
| SPAN | 경로 구간 | "③부터 ⑥까지 가는 길에 한 곳 있어요" | 경로 구간 하이라이트 | 지나가는 순서상 ③~⑥(양 끝 포함) 중 숨은 곳 수 = N |
| SIDE | 경로 편 | "가시는 길 오른편엔 두 곳 있어요" | 경로 기준 한쪽 음영 | 그 편 장소 중 숨은 곳 수 = N |
| NEIGHBOR | 앞뒤 이웃 | "이 앞뒤로 지나가는 두 곳 중 한 곳" | 지나가는 순서상 앞뒤 연결 | 바로 앞뒤 두 곳 중 숨은 곳 수 = N (처음·마지막 장소는 한쪽 두 곳) |
| KIND | 업종 | "카페 쪽엔 아무도 없어요" | 업종 필터 칩 | 그 업종 장소 중 숨은 곳 수 = N |
| ROAD | 길가 | "바로 길가에 있는 곳들 중엔 한 곳" | 경로를 따라 그린 띠 | 길가 장소 중 숨은 곳 수 = N |
| VOUCH | 보증 / 고발 | "5번은 깨끗해요" / "7번이 수상해요" | 핀 사이 화살표(초록 / 빨강) | 5번이 숨은 곳이 아님 / 7번이 숨은 곳임 |
| REVEAL | 정체 확인 | "6번 사람, 진짜 택시기사 맞아요" | 대상 핀에 확인 배지 | 대상의 실제 직업이 겉으로 밝힌 직업과 같음 |

### 거짓 단서를 만드는 규칙
- **개수 단서:** 참값이 아닌 값을 말한다. 범위는 0부터 판의 숨은 곳 수까지다.
- **보증과 고발:** 참·거짓을 뒤집는다.
- **정체 확인:** 반대로 말한다.

## 5. 공통 역할 (12개, 4분류)

모든 사업부에 나오는 공통 역할(티어 1)이다. 사업부 고유 역할은 7절에 있다.

정직한 역할은 판마다 한 명씩만 나온다(중복 없음). 그래서 **같은 직업을 밝힌 사람이 두 명이면 한 명은 가짜**다. 이게 핵심 추리 고리다.

| 분류 | 역할 | 단서 | 특징 |
|---|---|---|---|
| 정직(선) | 노점상 | RADIUS | 한 자리에서 오래 장사해서 주변을 다 안다 |
| 정직 | 택시기사 | SPAN 또는 ROAD | 길을 꿰고 있다 |
| 정직 | 드론 유튜버 | SIDE | 위에서 내려다본다 |
| 정직 | 동네 토박이 | NEIGHBOR | 이웃 사정을 잘 안다 |
| 정직 | 배달 라이더 | KIND | 가게 종류별로 잘 안다 |
| 정직 | 경비원 | VOUCH | 특정 장소를 보증하거나 고발한다 |
| 정직 | 순찰 경관 | REVEAL | 가장 가까운 장소 제보자의 정체를 확인해준다. **오염되지 않고, 아무도 경관으로 위장할 수 없다**(쉬운 판의 기준점 역할). 단, 보이스피싱 사업부에서는 예외다(7절) |
| 말썽꾼(선) | 오지랖 주민 | 개수 단서(RADIUS / SPAN / SIDE / NEIGHBOR / KIND 중) | 숫자를 **항상 실제보다 1 많게** 말한다. 급습하면 신뢰도 -2 |
| 말썽꾼 | 취객 | 자신이 믿는 역할의 단서 | 용의 목록에는 있지만 이번 판에는 없는 정직 역할이 자기라고 착각한다. 단서는 항상 거짓이다. 급습하면 신뢰도 -2 |
| 조직원(악) | 행동대원 | 위장한 역할의 단서(거짓) | **이번 판에 있는 정직 역할**로 위장한다. 여러 명 나올 수 있다 |
| 조직원 | 협박꾼 | 위장한 역할의 단서(거짓) | 용의 목록에 있지만 이번 판에 없는 정직 역할로 위장한다. 가장 가까운 정직 제보자 1명을 **오염**시킨다 |
| 보스(악, 최대 1) | 보스 | 위장한 역할의 단서(거짓) | 용의 목록에 있지만 이번 판에 없는 정직 역할로 위장한다. **반경 1km 안의 정직 제보자 전원을 오염**시킨다(공간 오염) |

- **오염:** 오염된 정직 제보자는 거짓 단서를 말한다. 겉으로 밝힌 직업은 진짜다. 말썽꾼과 경관은 오염되지 않는다.
- **용의 목록:** 브리핑에서 이번 판에 나올 수 있는 정직 역할 목록을 보여준다. 실제로 나온 역할에 1~2개의 미끼를 섞어서 보여준다.
  - 그래서 "판에 없는 역할로 위장"할 여지가 생긴다.
  - 목록에 아예 없는 직업을 대는 사람은 없다.
  - v0의 정직 역할은 7개뿐이라, 보통 난이도에서는 미끼가 1개밖에 안 된다. 위장하는 사람들이 같은 미끼 직업을 겹쳐 대도 된다(둘 다 가짜). 역할을 더 늘리는 건 v1 과제다.

### 난이도별 구성 (9곳, 통화 수는 v1 통계로 정함)
| 난이도 | 숨은 곳 | 말썽꾼 | 정직 | 통화 | 메모 |
|---|---|---|---|---|---|
| 쉬움(튜토리얼) | 행동대원 ×2 | 0 | 7 | 5 | 오염 없음. 같은 직업 두 명 찾기 위주 |
| 보통 | 행동대원 + 협박꾼 | 1 | 6 | 5 | 오염 1명 |
| 어려움 | 행동대원 + 협박꾼 + 보스 | 1 | 5 | 7 | 공간 오염 |
| 보이스피싱(데모) | 사칭범 + 협박꾼 | 1 | 6 | 6 | 사칭범은 경관 행세를 한다(경관이 두 명 나온다). 익명 제보 1곳 |

- **사칭범(보이스피싱 사업부):** 행동대원처럼 판에 있는 직업으로 위장하는데, 순찰 경관 행세도 할 수 있다. 가짜 경관의 정체 확인은 거짓이다.
- **익명 제보:** 직업을 밝히지 않고 '들은 소문'(숫자 단서)을 말한다. 진실 규칙은 다른 제보자와 같다.

## 6. 이동과 차량 데이터 연동

| 차량 데이터 | 게임 규칙 |
|---|---|
| ETA | 마감 시간이 된다. 통화(탐문) 수는 난이도별 기본값에 ETA 보정을 더한다. 통화 한 번에 이동 시간이 흐른다(도착 5분 전까지의 시간 ÷ 통화 수). ETA가 12분보다 짧으면 쉬움 난이도로 고정한다 |
| ETA 변동(정체 등) | 마감은 실시간으로 따라 바뀐다. 예산은 시작할 때 값으로 고정한다 |
| 현재 위치 vs 길가 장소 | 길가 장소에 다가가면 **잠복 찬스**(TBT 경고 카드처럼): "300m 앞 오른편 ⑤ — 잠복 가능". 수락하면 통화를 쓰지 않고 탐문하고, **그 단서는 엔진이 참으로 보장**한다(거짓말과 오염 무시). **지나치면 기회가 사라진다** |
| 터널 진입 | **은폐**: 다음 탐문 제보자의 직업이 가려진다("얼굴이 잘 안 보여요"). 위장을 판별할 수 없게 된다 |
| 정차 30초 이상(신호 대기) | 보너스 탐문 +1. 판당 최대 1회 |
| 시각(낮 / 밤) | 앰비언트 라이트 색과 BGM이 바뀐다. 밤에는 야간 잠복 분위기(경광등 색 액센트) |
| 도착 5분 전 | 최종 단계. 탐문할 수 없고 출동(급습)만 가능하다. 출동하면 경찰 아이콘이 지도 위를 달려가 도착하면 결과가 나온다 |
| 목적지 변경, 하차, 제어권 전환 요청 | 즉시 일시정지하고 상태를 저장한다. 다음 이동에서 이어할 수 있다 |

## 7. 런 구조 (풀 로그라이트)

Dupery의 "지역 캠페인 3개 → 최종 보스 런" 구조를 출퇴근 리듬에 맞게 옮긴다.

- **기본 단위:** 이동 1회 = 사건 1개.
- **런 1회 = 사업부 하나를 무너뜨리는 작전:** 사건 4~6개 + 간부 사건 1개. 출퇴근 기준 3~4일 분량이다.
- **최종 목표:** 사업부 3개를 모두 무너뜨리면 보스 런이 열린다.
- **실패해도 잃는 건 진행 중인 런뿐이다.** 해금한 것과 보스 단서 조각은 남는다. 2주치 진행이 한 번에 날아가지 않게 하기 위해서다.

### 흐름
```
[작전 지도] → 리드 선택 → 사건 → 보상 선택 → 사건 → … → 간부 사건 → 런 클리어
                                                              ↓
                                         보스 단서 조각 + 해금 티어 (영구)

사업부 3개 클리어 → 보스 런 (세 사업부 역할이 섞인 사건들 → 보스 사건)
```

### 리드 선택
런을 시작할 때 첩보(리드) 3개 중 하나를 고른다. 리드가 정하는 것:
- 사업부(아직 무너뜨리지 않은 곳 우선)
- 사건 수: Standard 4~5, Challenge 6~7
- 주요 용의 역할 3개: 런 내내 용의 목록에 고정된다
- 시작 관할 크기: 9곳 또는 12곳

### 사업부 3개 (지역)
| 사업부 | 분위기 | 고유 규칙 | 고유 역할 예시 | 간부 |
|---|---|---|---|---|
| 보이스피싱 콜센터 | 사칭과 전화 | **사칭:** 이 사업부에서는 순찰 경관도 사칭될 수 있다(공통 규칙을 깨는 반전). 일부 제보는 익명 전화로 들어와 직업이 공개되지 않는다 | 사칭범(경관으로 위장), 대포폰 상인(익명 제보를 만든다) | 총책 |
| 불법 도박 하우스 | 숫자와 판돈 | **베팅:** 급습 전에 판돈을 걸 수 있다. 맞히면 신뢰도를 얻고, 틀리면 손실이 2배다 | 딜러(이웃 제보자의 숫자를 ±1 조작), 사채업자(오급습하면 신뢰도 추가 -1) | 하우스장 |
| 밀수 물류망 | 이동과 시간 | **화물 이동:** 사건 도중 한 번, 운반책이 가장 가까운 장소로 옮겨간다. 시점은 차가 경로 중간 지점을 지날 때다 | 운반책(이동), 세관 브로커(길가 제보자를 오염) | 물류 팀장 |

- **간부 사건:** 사업부의 마지막 사건이다.
  - 간부가 반드시 등장하고 고유 능력이 있다.
  - 진행이 길어서 ETA 25분 이상인 이동에서만 시작한다("오늘 퇴근길에 간부 사건 할까요?").
- **보스 단서 조각:** 간부 사건을 해결하면 1~2개를 얻는다.
  - 예: "보스는 판에 없는 직업인 택시기사로 위장한다", "보스는 강 남쪽 장소에 숨는다"
  - 보스 사건에서 모은 조각이 브리핑에 확정 정보로 들어간다. 조각을 많이 모을수록 쉬워진다.
- **이동 규칙과 검증:** 운반책이나 정체 구간처럼 조직원이 움직이는 규칙이 있다.
  - 이동은 "가장 가까운 장소로"처럼 결정적으로 정하고, 움직였다는 사실은 Gleo가 알려준다.
  - 솔버는 이동 전후 상태를 모두 넣어서 검증한다.

### 사건 사이 보상
사건을 해결하면 둘 중 하나를 고른다.
- **관할 확대:** 장소 9곳 → 12곳. 어려워지는 대신 이후 보상이 커진다. 9곳인 채로 런의 절반을 넘기면 강제로 확대된다.
- **단서 카드 3장 중 1장:**
  - 신뢰도 회복 +1~2
  - 힌트권 또는 잠복권(잠복 찬스 1회 추가)
  - 역할 고정(특정 역할이 반드시 나오거나 안 나오게)
  - quirk 추가(위험이 커지는 대신 보상 증가)
  - 사건 추가(런이 길어지는 대신 보상 기회 증가)

### 신뢰도와 실패
- **신뢰도는 런 안에서 이어진다.** 시작 5, 최대 7이고, 0이 되면 해임되어 런이 끝난다.
- **사건 실패**(도착할 때까지 다 못 잡음): 남은 조직원 1명당 신뢰도 -1, 보상 없음. 런은 계속된다.
- **Standard:** 사건을 해결할 때마다 신뢰도가 1 자동 회복된다.
- **Challenge:** 자동 회복이 없다.
- **짧은 이동:** ETA 12분 미만이면 런에 영향을 주지 않는 "연습 사건"만 할 수 있다.

### quirk (사건 규칙 변형, 차량 데이터 연동형 위주)
| quirk | 효과 |
|---|---|
| 야간 작전 | 해가 진 뒤 이동에서만 붙는다. 오염 반경 2배, 보상 2배 |
| 정체 구간 | ETA가 5분 이상 늘면 탐문 +1. 대신 숨은 조직원 한 명이 가장 가까운 장소로 이동 |
| 터널 공포 | 모든 터널 진입이 은폐를 일으킨다 |
| 우천 | 비가 오면(와이퍼·강우 센서) 반경 단서의 반경이 절반 |
| 급행 | 탐문 예산 -1, 보상 카드 +1장 |
| 단골집 | 자주 가는 장소가 반드시 1곳 들어가고, 그곳에 조직원이 숨어 있을 확률이 높다 |

### 메타 진행 (해금)
- 공통 역할 12개(5절)는 처음부터 열려 있다.
- 사업부마다 역할과 quirk 티어가 3개씩, 총 9개 있다. 그 사업부 런을 클리어할 때마다 다음 티어가 열린다.
- 보스 런은 사업부 3개를 각각 한 번씩 클리어하면 열린다(약 2주 분량).
- 9티어를 모두 열면 Challenge 모드가 열린다.

## 8. 엔진과 LLM의 역할 분리

> 프로토타입 구현과 검증 결과: [prototype-report.md](prototype-report.md)

```
[POI·경로] → ①보드 생성 → ②진실 배정 → ③단서 생성 → ④검증(솔버) → ⑤난이도 산정
                                                            ↓ 단서 JSON (진위 정보 제외)
                                               ⑥LLM 대사화 → ⑦대사 검증 → TTS
```

1. **보드 생성:** 3절의 규칙대로 장소 9곳을 고른다.
2. **진실 배정:** 난이도표에 따라 숨은 곳 H, 각 장소의 실제 역할, 겉으로 밝힐 역할, 오염 대상을 정한다.
3. **단서 생성:** 각 제보자의 단서 유형에서 파라미터 후보를 만든다(반경, 절반 방향, 종류, 대상 장소).
   - 실제 좌표로 참값을 계산한다.
   - 역할 규칙(정직=참, 오염/악=거짓, 오지랖=+1)으로 최종 진술값을 정한다.
   - 정보량이 큰 파라미터를 우선 고른다. 모든 경우에 똑같이 참인 단서는 정보가 없으므로 제외한다.
4. **검증:** 플레이어가 볼 수 있는 정보와 일치하는 "가능한 세계"를 모두 대입한다.
   - 가능한 세계 = (H, 실제 역할, 오염) 조합이다.
   - 두 가지 조건을 확인한다.
     - (a) 9곳 전부 탐문했을 때 H가 하나로 정해지는가?
     - (b) 예산 안의 탐문 조합 중 H가 하나로 정해지는 조합이 있는가?
   - 9곳, 숨은 곳 3곳 이하라 경우의 수는 수만 가지 이하다. 기기에서 바로 계산할 수 있다.
5. **난이도 산정:** H를 하나로 정하는 데 필요한 최소 탐문 수와, 추론 단계 수를 계산해서 난이도로 쓴다.
6. **LLM 대사화:** 입력은 캐릭터 프로필(직업, 성격, 말투), 장소 묘사, 단서 JSON이다.
   - **진위 정보는 LLM에 넘기지 않는다.** 말투로 거짓말이 들통나는 불공정을 막기 위해서다.
7. **대사 검증:** 대사에 단서의 장소 번호·이름과 숫자가 그대로 들어 있는지 확인한다. 실패하면 템플릿 문장으로 대체한다.

### 추가 질문 규칙
- **사실 시트:** 직업, 성격, 장소 묘사, 자기 단서(다시 말하기 허용).
- **금지:** 다른 장소가 숨은 곳인지 아닌지 언급하기, 새로운 숫자나 장소 언급하기.
- **필터:** 출력에 금지 요소가 있으면 다시 생성한다. 그래도 실패하면 "글쎄요, 제가 아는 건 아까 말한 게 다예요"로 대체한다.

### 단서 JSON 예시
```json
{
  "place": 2,
  "shownRole": "노점상",
  "clue": { "type": "RADIUS", "center": 2, "radiusM": 1000, "count": 1 }
}
```
- 엔진 내부에만 `isTruthful`, `actualRole`, `tainted` 필드를 따로 둔다. 이 필드들은 LLM에 넘기지 않는다.

## 9. 음성 대화 예시 (한 판 축약)

> 보드: ①한강공원(길가) ②시청역 ③단골 카페 ④도서관 ⑤전통시장(길가) ⑥미술관 ⑦전망 타워 ⑧단골 헬스장 ⑨광장(길가)
> 난이도: 쉬움. 숨은 곳 2곳(⑥, ⑧).

```
Gleo   형사님, 목적지까지 20분이에요. 이 근처 아홉 곳 중 두 곳에 조직원이 숨어들었다는 첩보예요.
       탐문은 다섯 번 할 수 있어요.
나     2번 탐문해줘.
노점상  (②) 여기서 30년 장사했어. 이 역에서 1킬로 안에 수상한 데가 딱 한 곳 있어.
       → 지도: ② 중심 1km 원. 원 안의 ③④⑥ 강조
나     어떤 사람이었어요?
노점상  모자 푹 눌러쓴 젊은 사람… 그 이상은 몰라.
Gleo   곧 5번 전통시장 옆을 지나가요. 잠복할까요?
나     응.
Gleo   잠복 성공. 5번 배달 라이더의 말은 확실해요.
라이더  (⑤) 카페 쪽엔 아무도 없어요.  → ③ 회색 체크(확정)
나     8번 탐문.
노점상  (⑧) 나도 이 동네 장사꾼인데, 헬스장 1킬로 안에 두 곳이나 있어!
Gleo   참고로, 노점상이라고 밝힌 사람이 두 명이에요.
나     8번 급습해.
Gleo   8번 헬스장 근처를 급습할까요? 틀리면 신뢰도가 2 떨어져요.
나     해.
Gleo   검거! 노점상으로 위장한 행동대원이었어요. 남은 조직원은 한 명이에요.
Gleo   터널에 들어왔어요. 다음 제보자는 얼굴이 잘 안 보일 거예요.
  …
Gleo   도착 5분 전이에요. 조직이 눈치챘어요. 이제는 급습만 할 수 있어요.
나     6번 급습.
Gleo   검거! 사건 해결이에요. 신뢰도 5를 지켰어요. 보상 카드를 골라주세요.
```

## 10. 화면 구성 초안

```
┌──────────────────────────────────────────────────────────┐
│ 도착 18분 │ 탐문 3/5 │ 신뢰도 ●●●●○ │ 남은 조직원 1 │ [정리] │
├──────────────────────────────────────────────────────────┤
│        ③카페             ⑤시장                             │
│            ( 1km 원 )               ⑦타워                   │
│   ①공원 ━━━━ [차] ━━━━━━━━━━━━━━━━━━━━━━━━━ 경로 ━━ [도착] │
│            ②역          ⑥미술관           ⑧헬스장 [수갑]     │
│     ④도서관                               ⑨광장             │
├──────────────────────────────────────────────────────────┤
│ [제보자 카드]  ② 노점상                                     │
│ "이 역에서 1킬로 안에 수상한 데가 딱 한 곳 있어."               │
└──────────────────────────────────────────────────────────┘
```
- **지도:** 야간 도시 스타일(경광등 빨강·파랑 액센트)로 화면 전체를 쓴다. 3D 핀 9개(번호 배지), 차량, 경로선이 올라간다.
- **단서 레이어:** 최근 단서는 진하게, 이전 단서는 흐리게 그린다. 왼쪽 접이식 패널에 단서 칩 목록이 있고, 칩을 누르면 그 도형만 보여준다.
- **핀 상태:** 미탐문(회색), 탐문함(흰색), 의심 메모(빨간 테두리), 무고 메모(파란 테두리), 검거(수갑), 오급습(X), 은폐(안개).
- **제보자 카드:** 하단에 캐릭터 이미지와 자막을 띄운다. 큰 글씨로 최대 두 줄.
- **멀미 고려:** 카메라 이동은 느리고 짧게 한다. 정보는 음성이 먼저, 화면은 확인용이다.
- **탭 조작은 보조 수단:** 핀을 누르면 [탐문] [급습] [메모] 버튼이 나온다.
- **런 화면(사건 밖, 정차 중이나 출발 전에 보는 화면):**
  - 작전 지도: 사업부 3개, 진행 중인 런의 사건 칸, 모은 보스 단서 조각
  - 리드 선택: 카드 3장
  - 보상 선택: 카드 3장 또는 관할 확대
  - 음성으로도 고를 수 있다("두 번째 카드")

| P2 | 검거, 보스 검거 컷신 | 2 | 핀 위 스포트라이트 |

| P2 | 간부 3명 + 보스 흉상 | 4 | 간부·보스 사건 연출 |

## 12. 해커톤 데모 시나리오

- **차량 데이터 가짜 구현:** 인터페이스 하나로 위치, 경로, ETA, 속도, 터널 여부, 정차 여부, 시각을 제공한다.
  - 가짜 경로 재생기가 미리 녹화한 경로 JSON을 배속(×4~×10)으로 재생한다.
  - 터널 구간과 신호 대기 이벤트는 스크립트로 넣는다.
- **장소 데이터:**
  - 시연용 고정 경로 1개(약 20분 분량)에 장소 9곳 JSON(이름, 좌표, 종류, 길가 여부)을 준비한다.
  - 무작위 생성 시드도 2~3개 준비한다.
- **음성:** Gleo 인터페이스로 추상화한다.
  - 해커톤에서는 Android 음성 인식 + LLM API + TTS로 구현한다.
  - 실제 Gleo SDK로 교체할 수 있게 만든다.
- **실행 환경:** Godot 4로 만든 Android 앱(GDScript, Compatibility 렌더러). 가능하면 Android Studio의 Automotive 에뮬레이터에서 시연한다.
- **퍼즐 공급:** Python 퍼즐 공장에서 검증한 퍼즐을 JSON 퍼즐 팩으로 내보내 Godot이 읽는다. Godot 쪽에는 솔버가 필요 없다([puzzle-pack-schema.md](puzzle-pack-schema.md)).
- **데모 골격:** [godot/](../godot/README.md). 지도, 단서 도형, 탐문·잠복·급습, 차량 진행 시뮬레이션까지 들어 있다.
- **로그라이트 범위:**
  - 구현: 사건 엔진, 보이스피싱 사업부 1개(사칭 규칙 포함), 사건 사이 보상 선택, 신뢰도 이월, 작전 지도 화면
  - 목업: 나머지 사업부 2개(잠금 표시), 해금 화면, 간부·보스 사건 예고
- **3~4분 데모 동선:**
  1. 작전 지도에서 리드 선택(보이스피싱 사업부)
  2. 브리핑
  3. 탐문 2회
  4. 잠복 찬스
  5. 같은 직업 두 명으로 위장 간파
  6. 경관인 줄 알았던 제보자가 사칭범으로 밝혀지는 반전
  7. 일부러 오급습 1회(신뢰도 하락 연출)
  8. 터널 은폐
  9. 최종 단계 급습, 승리
  10. 보상 카드 선택, 간부 사건 예고

## 13. 리스크와 결정 사항

### 리스크
| 리스크 | 대응 |
|---|---|
| 실제 상호의 이미지 훼손 | "근처에 숨어 있다"로 표현하고, 랜드마크와 공공장소를 우선으로 고른다 |
| 개인정보(자주 가는 곳) | 동의한 경우에만 쓰고, 기기 안에서만 처리하고, 집은 제외한다 |
| 장소 부족(시골, 고속도로) | 범위를 넓히고, 가상 장소를 섞고, 주변형으로 전환한다 |
| LLM이 사실과 다른 말을 함 | 진위 정보를 넘기지 않고, 대사를 검증하고, 실패하면 템플릿으로 대체한다 |
| 음성 인식 오류 | 번호로 부르는 방식을 우선하고, 급습 전에는 반드시 확인 질문을 한다 |
| 지도 가독성 | 장소 간격 700m 이상, 최근 단서 강조 |
| 멀미 | 오디오 위주로 하고 화면 애니메이션을 최소화한다 |
| 첫 판 진입 장벽 | 첫 판은 쉬움(거짓말 패턴 1종)으로 하고 Gleo가 규칙을 짧게 안내한다 |
| 로그라이트 런이 길어서 이탈 | 런을 사업부 하나(3~4일)로 쪼개고, 실패해도 해금과 보스 단서 조각은 남긴다 |
| 해커톤 범위 초과 | 사업부 1개만 완성하고 나머지는 목업으로 보여준다(12절) |

- **수치:** 숨은 곳 수, 탐문 예산 공식, 신뢰도(시작 5, 최대 7, 오급습 -2, 힌트 -1), 사업부당 사건 수는 가정값이다.
